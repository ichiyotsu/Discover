# TokiDiscover iOS

SwiftUI + WKWebView。纯逻辑包 `TokiDiscoverCore`（UrlNormalizer + UpdateChecker）可用 `swift test` 验证（需 Swift 工具链）。
App 本体需在 Xcode 打开 `TokiDiscover.xcodeproj` 验证 — Linux 环境无 Xcode，本仓库未在 Linux 上编译 iOS 本体（手写最小 pbxproj 壳）。
版本：MARKETING_VERSION 0.1.0 / CURRENT_PROJECT_VERSION 1，Info.plist 与之保持一致。
